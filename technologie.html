Školní projekt

Web o Egyptě,
vytvořený s AI.

Tento web vznikl jako školní projekt s využitím GitHub Copilotu. AI pomohla s návrhem struktury, českými texty a kódem; výsledek je statický web bez externích knihoven.

Co web používá

Jednoduché technologie.
Otevřený web.

01

HTML5

Struktura stránek, textový obsah, odkazy a sémantické prvky, jako jsou hlavička, navigace, hlavní obsah a zápatí.

02

CSS3

Vzhled, barvy, typografie, responzivní rozvržení pomocí Flexboxu a CSS Gridu i vlastní ilustrace vytvořené přímo v CSS.

03

GitHub Copilot

AI asistent použitý při tvorbě návrhu, textů a kódu. Výstup AI je vhodné kontrolovat, upravovat a ověřovat podle důvěryhodných zdrojů.

04

Bez JavaScriptu a knihoven

Web tvoří samostatné HTML stránky a jeden soubor CSS. Nepoužívá JavaScript, instalované balíčky ani externí obrázky.

Ukázka zadání pro AI

„Vytvoř český školní web o Egyptě alespoň se třemi propojenými stránkami. Použij přístupný HTML a responzivní CSS, uveď na úvodu, že jde o projekt vytvořený s pomocí AI, a popiš použité technologie.“

Nástroj: GitHub Copilot. Obsah a kód byly vytvořeny a upraveny pro tento školní projekt.
