# Egypt — zdroje a dokumentace

## Téma a účel

Český školní web o Egyptě. Obsahuje čtyři stránky: úvod, památky, kulturu a informace o projektu a použitých technologiích.

## Použitý AI nástroj

- **Nástroj:** GitHub Copilot v Visual Studio Code.
- **Využití:** návrh struktury webu, návrh českých textů, vytvoření HTML a CSS a úpravy responzivního zobrazení.
- **Kontrola:** texty jsou informační shrnutí; faktická tvrzení je vhodné porovnat s níže uvedenými zdroji. AI může vytvářet nepřesnosti.

## Ukázkové prompty

1. „Navrhni český školní web o Egyptě. Musí mít alespoň tři propojené stránky a úvodní stránka musí uvádět, že jde o školní projekt vytvořený s pomocí AI.“
2. „Vytvoř přístupné HTML stránky v češtině o egyptských památkách, kultuře a Nilu. Použij sémantické HTML a společné responzivní CSS.“
3. „Popiš na samostatné stránce technologie použité při tvorbě webu a přidej dokumentaci nástroje AI a zdrojů.“

## Technologie

- **HTML5** — obsah a sémantická struktura stránek.
- **CSS3** — vizuální styl, responzivní rozvržení (Flexbox a CSS Grid) a dekorativní ilustrace vytvořené pomocí CSS.
- **GitHub Copilot** — AI asistent při návrhu a tvorbě kódu a textů.
- Web nepoužívá JavaScript, externí knihovny ani obrázky. Google Fonts se načítají z externí služby; při nedostupnosti se použijí systémová náhradní písma.

## Informační zdroje

- UNESCO World Heritage Centre, *Memphis and its Necropolis – the Pyramid Fields from Giza to Dahshur*: <https://whc.unesco.org/en/list/86/>
- UNESCO World Heritage Centre, *Ancient Thebes with its Necropolis*: <https://whc.unesco.org/en/list/87/>
- Encyclopaedia Britannica, *Nile River*: <https://www.britannica.com/place/Nile-River>
- Encyclopaedia Britannica, *Rosetta Stone*: <https://www.britannica.com/topic/Rosetta-Stone>
- Encyclopaedia Britannica, *Koshari*: <https://www.britannica.com/topic/koshari>

Texty na webu jsou stručná převyprávění základních informací, nikoli doslovné citace. Vizuální návrh a CSS ilustrace byly vytvořeny pro tento projekt.

## Zveřejnění

Web tvoří statické HTML a CSS soubory a lze jej zveřejnit například pomocí GitHub Pages. Po zveřejnění doplň do školního odevzdání odkaz na GitHub repozitář a veřejnou adresu webu. Odkazy do MS Teams sdílí autor projektu.
